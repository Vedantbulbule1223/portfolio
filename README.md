## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The website will then be available locally.
